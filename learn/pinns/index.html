A curated 20-paper learning route

This teaching selection covers foundational methods, training mechanisms, variational formulations, multiscale representations, uncertainty and applications. It is an editorial learning route, not a citation ranking. All sixteen core papers now have published presentations,worked CPU examples and bilingual narration.

Local CPU budget

Default target: fewer than 5,000 parameters, at most 1,024 residual points, four CPU threads and a 90-second training cap per run. Paper14 uses a disclosed180-second cap for diagnostic sampling retries. Each paper states its actual settings, seeds and departures from the original benchmark. Failures and engineering modifications are disclosed.
