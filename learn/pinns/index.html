Small enough to run, clear enough to inspect

Paper 01 uses 1,297 trainable parameters, 384 collocation points and four CPU threads. The measured PINN training run took about 14.3 seconds. A short time window, [0, 0.2], replaces the paper's [0, 1] benchmark; the later sharp-layer challenge is deliberately outside this first exercise.

On a separate validation grid, this single seeded PINN run has 2.07% relative error; a data-only control has 31.15%. These are measured teaching results, not the paper's published accuracy or a statistical ranking. Both code and full traces are downloadable.

English narration, progressive reveals, physical animation, equation–schematic highlights and real training replay are included. Chinese slides and transcripts are available in reading mode. Published pages replay recordings and results; they do not train neural networks on visitors' devices.

Paper 02: measured results and scope

Clean data: λ₁ = 0.99136, λ₂ = 0.049467 in 16.6 seconds. One 1% noise realisation: 0.98336 and 0.049225 in 15.0 seconds. Truth: 1 and 0.05. The data-only control fits the field well but leaves these coefficient parameters unchanged.

Four CPU threads, 1,299 parameters, 256 observations; residual tests at the same coordinates. Teaching viscosity 0.05 and time window [0, 0.5] differ from the original benchmark. Noise standard deviation is 1% of clean-observation standard deviation; a single seed is not uncertainty quantification. English narration is cached; Chinese slides/transcripts use reading mode. The browser replays results without training.

The format for every paper

Physical question → paper idea → explained equations → implementation → a small controlled experiment → independent validation → limitations → why the next paper is needed. Results include the actual hardware budget, seed and departures from the original benchmark.

Need the foundations first?

The earlier six-chapter, two-hour PINNs foundations course remains available as optional preparation. It is a general primer, not six separate paper implementations.

Local execution budget

The default target is a network below 5,000 parameters, at most 1,024 collocation points and a 90-second training cap per run on four CPU threads. Each paper states its own actual settings. We will choose analytic references, quadrature or small independently checked computations instead of requiring large simulations.
