1. From one paper to a testable implementation

Today we will implement a small Burgers PINN through the foundational Part I paper by Raissi and colleagues. We will start from the physical problem, then connect the residual to executable code. Finally, we will inspect actual experiments and independent evidence, separating a method implementation from full benchmark reproduction.

2. What does this paper change?

Our primer explained what a PINN is, so we can now ask what the foundational paper actually implements. Sparse labels tell a network only a few values. A physics test adds information about how predictions must change between those values.

The second box is that physics test, built by differentiating the same network rather than training a separate physical model. We will implement the continuous-time Burgers example from Part I, then test its predictions against an independent reference.

中文讲稿

先修课解释了什么是 PINN，现在我们要问奠基论文具体实现了什么。少量标签只告诉网络一些位置的数值。物理检验还约束这些位置之间的变化方式。

右侧的物理检验来自同一个网络的导数，不是另一个独立训练的物理模型。本课实现第一部分的连续时间 Burgers 算例，再用独立参考解检验预测。

The evolving curve gives us a question: which changes are physically allowed? A subscript t means the first time derivative, a subscript x means the first spatial derivative, and double x means the second spatial derivative. The product u times u x is nonlinear transport, so local field values affect how the profile moves.

The right side describes diffusion of the same profile, and nu is the positive viscosity coefficient. Its value is zero point zero one divided by pi, matching the paper. The highlighted curve and equation express one balance between time change, transport and smoothing.

中文讲稿

变化的曲线带来一个问题：哪些变化符合物理规律？下标 t 表示一阶时间导数，下标 x 表示一阶空间导数，两个 x 表示二阶空间导数。u 乘 u 的空间导数表示非线性输运，局部场值会影响轮廓的传播。

右侧描述同一轮廓的扩散，nu 是正的黏性系数。它取零点零一除以圆周率，与论文一致。高亮的曲线和公式表达的是时间变化、输运与平滑之间的同一个平衡。

The balance law alone allows many solutions, so we must specify the experiment. At time zero, the field is the negative sine of pi times x, shown by the dashed curve. The two endpoints remain at zero throughout the experiment.

The first condition selects the starting profile and the endpoint conditions select its boundary behaviour. All three conditions supply labelled field values, whereas interior equation tests do not supply field labels. Keeping that distinction clear will make the training loss easier to understand.

仅有平衡方程还允许许多解，因此还要指定具体实验。在零时刻，场值是负的正弦函数，图中的虚线给出了这个起始轮廓。两个端点在整个实验中始终取零。

第一个条件选择起始轮廓，端点条件规定边界行为。这些条件提供带标签的场值，而内部的方程检验点不提供场值标签。区分这两类信息，后面的训练损失就容易理解。

6. The network represents a function

(x,t)⟼uθ(x,t)(x,t)\longmapsto u_\theta(x,t)(x,t)⟼uθ​(x,t)

We now know the field we want, but we still need a trainable representation. The input pair contains the position x and time t. The symbol theta denotes all network weights and biases, and u theta is its scalar field prediction.

The arrow means evaluating that one function at any requested coordinate. Our small implementation uses three hidden layers with twenty-four tanh units each. Tanh is smooth, which matters because the physical test needs a second spatial derivative.

中文讲稿

我们已知道要寻找怎样的场，现在还需要一个可训练的表示。输入是一对坐标，包含位置 x 和时间 t。theta 表示网络的全部权重和偏置，u theta 是网络给出的标量场预测。

箭头表示在任意查询坐标上计算同一个函数。本机实现使用三个隐藏层，每层二十四个双曲正切单元。双曲正切是光滑函数，这一点很重要，因为物理检验需要二阶空间导数。

7. Differentiate coordinates before updating parameters

uθ → autodiff  (uθ,t,uθ,x,uθ,xx)u_\theta\ \xrightarrow{\ \mathrm{autodiff}\ }\ (u_{\theta,t},u_{\theta,x},u_{\theta,xx})uθ​  autodiff ​ (uθ,t​,uθ,x​,uθ,xx​)

A trainable function is not yet a physical test, so we now differentiate it. Automatic differentiation follows the chain rule through the network to obtain derivatives with respect to x and t. These are coordinate derivatives, not the parameter gradients used to update theta.

The second box collects the time derivative, spatial slope and spatial curvature. During optimisation, parameter gradients must pass through these derivative calculations as well. Preserving that computation graph is why the code requests create graph.

中文讲稿

可训练函数还不是物理检验，因此现在要对它求导。自动微分沿着网络应用链式法则，得到关于 x 和 t 的导数。这些是坐标导数，不是更新 theta 时使用的参数梯度。

第二个框收集时间导数、空间斜率与空间曲率。优化时，参数梯度还必须穿过这些求导计算。因此代码需要保留计算图，也就是设置 create graph。

8. What does the residual test?

fθ=uθ,t+uθuθ,x−νuθ,xxf_\theta=u_{\theta,t}+u_\theta u_{\theta,x}-\nu u_{\theta,xx}fθ​=uθ,t​+uθ​uθ,x​−νuθ,xx​

The derivatives let us turn the balance law into a numerical test. The paper calls the resulting residual f, and here f theta means the residual of our predicted field. We move diffusion to the left, so a physically consistent prediction should make this expression close to zero.

The second box is the local mismatch at one chosen coordinate. Residual zero checks agreement with the equation at that point, not agreement with the initial profile or with every other point. That is why we still need both labelled conditions and many independent tests.

中文讲稿

这些导数让我们能够把平衡方程变成数值检验。论文把得到的残差称为 f，这里 f theta 表示预测场的残差。把扩散项移到左侧后，符合物理的预测应当让这个表达式接近零。

第二个框表示某个查询坐标上的局部失配。残差为零只检验该点是否符合方程，不代表初始轮廓正确，也不代表其他位置都正确。因此仍然需要条件标签和独立检验。

9. Labels and equation tests are different

In the classroom: narration-driven samples animation or actual-result replay.

A local test leaves a practical question: where should we evaluate it? In this space-time diagram, x is horizontal and t is vertical. Gold points on the initial and boundary edges have known field values, while cyan interior points are coordinates where we test the equation.

The cyan points are called collocation points, and no reference solution is used as their training label. Our implementation fixes these points using one random seed. Validation later uses different coordinates, so it can detect mistakes hidden by the training set.

中文讲稿

局部检验留下一个实际问题：应该在哪里检验？在这幅时空图里，x 是横轴，t 是纵轴。初始边和边界上的金色点有已知场值，内部蓝色点则用于检验方程。

这些蓝色点称为配点，不会拿参考解作为训练标签。本实现用固定随机种子生成这些点。之后在不同坐标上验证，才有机会发现训练点掩盖的问题。

10. First constrain the known field values

Lu=1Nu∑i=1Nu∣uθ(xui,tui)−yi∣2\mathcal L_u=\frac{1}{N_u}\sum_{i=1}^{N_u}\left|u_\theta(x_u^i,t_u^i)-y_i\right|^2Lu​=Nu​1​i=1∑Nu​​​uθ​(xui​,tui​)−yi​​2

The gold points now become a measurable fitting objective. N u is the number of labelled points, i indexes one such point, and y i is its known field value. The coordinate pair with subscript u identifies that labelled location.

Subtract the label from the prediction, square the difference, then average over all labelled points. This mean squared error is called L u. Our labels come only from the initial and boundary conditions, so a small data loss alone cannot establish correct interior evolution.

中文讲稿

现在把金色标签点变成可计算的拟合目标。N u 是标签点的总数，i 表示其中一个点，y i 是该点的已知场值。带下标 u 的坐标对表示这个标签所在的位置。

用预测值减去标签，将差平方，再对所有标签点取平均。这个均方误差称为 L u。标签只来自初始条件和边界条件，因此数据损失小，并不能证明内部演化正确。

11. Then test the interior physical balance

Lf=1Nf∑j=1Nf∣fθ(xfj,tfj)∣2\mathcal L_f=\frac{1}{N_f}\sum_{j=1}^{N_f}\left|f_\theta(x_f^j,t_f^j)\right|^2Lf​=Nf​1​j=1∑Nf​​​fθ​(xfj​,tfj​)​2

The data loss does not determine interior evolution, so we add an equation loss. N f is the number of collocation points, and j indexes one coordinate pair with subscript f. At each of these points we evaluate the residual, without using a field-value label.

Square those residuals and average them to obtain L f. This is a finite collection of physics tests, not a proof that the differential equation holds everywhere. In particular, changing which points are tested can change what the trained model misses.

中文讲稿

数据损失没有确定内部演化，所以再加入方程损失。N f 是配点总数，j 表示带下标 f 的一对配点坐标。我们在每个配点计算残差，不使用场值标签。

将这些残差平方后取平均，就得到 L f。这是有限个物理检验，不是方程在所有位置成立的证明。特别是，改变检验点的分布，可能改变模型遗漏的问题。

12. Both losses update the same parameters

L(θ)=Lu(θ)+Lf(θ)\mathcal L(\theta)=\mathcal L_u(\theta)+\mathcal L_f(\theta)L(θ)=Lu​(θ)+Lf​(θ)

We now have two complementary tests, so the basic paper formulation adds their mean squared losses. Both terms depend on the same theta. Lowering only one term can leave the other requirement unsatisfied, even when the total curve looks reassuring.

Our implementation first uses Adam updates and then a small full-batch L-BFGS refinement. L-BFGS is a quasi-Newton optimisation method, and the Adam warm-up is a teaching implementation choice rather than the paper benchmark protocol. Neither optimiser gives us a global-convergence guarantee.

中文讲稿

现在已有两个互补的检验，基础论文方法把两个均方损失相加。两项损失都依赖同一组 theta。只降低其中一项，仍可能无法满足另一项，即使总损失曲线看起来很好。

本实现先用 Adam 更新，再进行少量全批次 L-BFGS 精修。L-BFGS 是一种拟牛顿优化方法，先用 Adam 预热是教学实现的选择，并非原论文基准流程。两种优化器都不提供全局收敛保证。

14. What changes to fit a local CPU?

Before reading a result, we must separate the paper method from our resource choices. The original Burgers example spans time zero to one and uses ten thousand collocation points. Its reported accuracy is not the target of this small lesson.

Our version stops at time zero point two, uses three hundred eighty-four collocation points and 1297 trainable parameters. It runs on four CPU threads with a per-run time cap and needs no GPU. Shortening the time window avoids the paper's later sharp-layer challenge, so comparisons must state that simplification.

中文讲稿

读实验结果之前，要先区分论文方法和本机资源选择。原文 Burgers 算例覆盖零到一的时间区间，并使用一万个配点。原文报告的精度不是本小实验的目标。

本版本只算到零点二，使用三百八十四个配点和 1297 个可训练参数。程序使用四个 CPU 线程，单次运行有时间上限，不需要显卡。缩短时间区间避开了原文后期的尖锐内层难题，因此比较时必须说明这一简化。

17. Validation must ask a different question

ε=∥uθ−uref∥2∥uref∥2\varepsilon=\frac{\|u_\theta-u_{\rm ref}\|_2}{\|u_{\rm ref}\|_2}ε=∥uref​∥2​∥uθ​−uref​∥2​​

The control is informative only if our reference is trustworthy, so now we examine the checks. The symbol epsilon is relative solution error, and the norm measures the Euclidean length of field values on a separate eighty-one by seventeen grid. The subscript ref means an independent Cole-Hopf reference evaluated by numerical quadrature.

We refine quadrature from ninety-six to one hundred sixty nodes and check initial and endpoint values before training. We also test the trained differential residual on five hundred twelve new random coordinates. Solution error and residual error answer different questions, so neither number should replace the other.

中文讲稿

只有参考解可信，对照实验才有意义，因此现在检查验证方法。epsilon 表示相对解误差，范数衡量独立的八十一乘十七网格上场值向量的欧氏长度。下标 ref 表示通过数值求积计算的独立 Cole-Hopf 参考解。

训练前先把求积节点从九十六增加到一百六十，并检验初值与端点值。训练后还在五百一十二个新的随机坐标上检验微分残差。解误差和残差误差回答不同问题，不能用一个数字代替另一个。

18. What does this result not establish?

Those independent checks strengthen the result, but they do not remove every limitation. A small training loss is not a global PDE guarantee. Our short-window success also says little about resolving the sharp internal layer at later times.

The second box requires evidence beyond one convenient experiment, including repeated seeds and sensitivity to collocation points. We deliberately avoid claiming that this PINN is faster than a conventional solver. The lesson establishes an understandable implementation and a local diagnostic example.

中文讲稿

独立检验增强了结果的可信度，但没有消除所有局限。训练损失小，并不保证方程在整个区域上成立。短时间区间的成功，也不能说明后期尖锐内层能够被正确解析。

第二个框需要更多证据，例如重复随机种子并检查配点敏感性。这里不声称 PINN 比常规数值求解器更快。本课建立的是可理解的实现和一个本机诊断案例。

19. Which part of the paper did we implement?

We have implemented one path through the paper, so we should locate it within the full contribution. Continuous-time models input space and time together and test differential residuals. That is the left-hand formulation used throughout this lesson.

The right-hand formulation uses structured time-stepping relations and multi-output networks for intermediate stages. The paper also studies other equations, but we have not reproduced those experiments here. A later implementation can add that formulation after the basic residual and validation ideas are secure.

中文讲稿

我们实现了论文中的一条路线，现在要把它放回完整论文的位置。连续时间模型同时输入空间与时间，并检验微分残差。这就是本课一直使用的左侧方法。

右侧方法使用结构化时间推进关系，以及输出中间阶段的多输出网络。论文还研究其他方程，但本课没有复现那些实验。待残差和验证思路掌握后，后续可以再实现这种形式。

21. Why should the next paper infer parameters?

This implementation assumed that viscosity was known, so one important scientific question remains unanswered. Given only observations of the evolving field, could the method identify the governing coefficient? That changes which quantities are trainable, rather than merely making the network larger.

The next presentation studies Part II on data-driven discovery of differential equations. We will reuse a small Burgers model with unknown coefficients, then test the role of observations and noise. Open Paper 02 to continue from solving a field to identifying its law.

中文讲稿

本次实现假定黏性已知，因此还有一个重要科学问题没有回答。只给演化场的观测，能不能识别方程系数？这改变的是哪些量需要训练，而不只是把网络做大。
