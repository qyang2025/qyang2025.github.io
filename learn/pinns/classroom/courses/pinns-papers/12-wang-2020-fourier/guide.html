1. Paper12: Fourier features and multiscale representations

First use a rod with broad and fine temperature variations to explain why spatial frequency matters. Then connect Fourier maps, shared branches and full spatial differentiation to the physical loss. Finally replay all CPU controls, inspect complete field and mode errors, and explain why multiple scales do not guarantee an improvement.

中文讲稿

先用同时包含宽尺度与细尺度温度变化的杆，解释空间频率为何重要。再把傅里叶映射、共享分支与完整空间求导连接到物理损失。最后回放全部 CPU 对照，检查完整场与模态误差，说明为什么多尺度不保证改善。

2. From weighting losses to changing the representation

The previous paper connected training rates to the neural tangent kernel. Loss weights changed the influence of objectives, but did not fully address which spatial patterns the network prefers.

This paper changes the coordinate representation through Fourier features. We will ask how this changes preferred patterns, then test a small multiscale physical problem on the CPU.

中文讲稿

上篇把训练速率与神经切线核联系起来。损失权重改变各目标的影响，但没有完全回答网络更偏爱哪些空间模式。

本篇通过傅里叶特征改变坐标表示。我们先问它如何改变偏爱的模式，再用 CPU 检验一个小型多尺度物理问题。

5. Small ripples can have large curvature

−uxx=ff=4π2[sin⁡(2πx)+3.6sin⁡(12πx)]\begin{gathered}-u_{xx}=f\\f=4\pi^2[\sin(2\pi x)+3.6\sin(12\pi x)]\end{gathered}−uxx​=ff=4π2[sin(2πx)+3.6sin(12πx)]​

The subscript x x denotes the second spatial derivative, and f is the prescribed signed heat source. Differentiating a sine twice multiplies its amplitude by its angular frequency squared.

Consequently, the small temperature ripple contributes a larger source amplitude than the broad mode. Learning a large source contribution accurately is not the same as recovering the entire temperature field accurately.

中文讲稿

下标 x x 表示空间二阶导数，f 是给定的有正有负热源。正弦求两次导数后，幅值乘以角频率的平方。

因此，小温度波纹对热源的幅值贡献反而大于宽尺度模式。准确学习一个很大的热源分量，不等于准确恢复整个温度场。

6. Kernel eigenvectors describe preferred shapes

Kqj=μjqj,cj(τ)=e−μjτcj(0)Kq_j=\mu_jq_j,\qquad c_j(\tau)=e^{-\mu_j\tau}c_j(0)Kqj​=μj​qj​,cj​(τ)=e−μj​τcj​(0)

Q j is an eigenvector of the empirical kernel K, a spatial pattern sampled on the evaluation points. Mu j is its eigenvalue, and c j is the error projected onto that direction.

For a fixed kernel under continuous gradient flow, that coefficient decays exponentially in optimisation time tau. Our small nonlinear network need not keep its kernel fixed, so this is an interpretation rather than a prediction theorem for our runs.

中文讲稿

q j 是经验核 K 的特征向量，也就是评价点上采样的空间形状。μ j 是对应特征值，c j 是误差在这个方向上的投影。

固定核的连续梯度流中，这个系数随优化时间 τ 指数衰减。我们的小型非线性网络不一定保持常核，所以这里只作解释，不当作运行结果的预测定理。

7. Map position into sine and cosine features

γB(x)=[cos⁡(2πBx),  sin⁡(2πBx)]\gamma_B(x)=[\cos(2\pi Bx),\;\sin(2\pi Bx)]γB​(x)=[cos(2πBx),sin(2πBx)]

Gamma is a coordinate mapping, and B contains randomly drawn frequencies in cycles per unit length. The two illustrative curves show that different frequency magnitudes create slowly or rapidly varying input features.

The mapping provides sine and cosine pairs to a nonlinear network, rather than declaring the final temperature to be a fixed Fourier series. We use the paper’s multiscale convention with an explicit two pi factor.

中文讲稿

γ 是坐标映射，B 包含随机抽取的频率，单位是每单位长度的周期数。两条说明曲线展示不同频率大小如何产生缓慢或快速变化的输入特征。

映射把正弦和余弦对交给非线性网络，并没有把最终温度限定成固定傅里叶级数。我们采用论文多尺度架构中显式含二圆周率的约定。

8. Bandwidth controls a distribution, not a guaranteed match

Bik=σiZik,Zik∼N(0,1)B_{ik}=\sigma_i Z_{ik},\qquad Z_{ik}\sim\mathcal N(0,1)Bik​=σi​Zik​,Zik​∼N(0,1)

Sigma i is the standard deviation for frequency branch i, and Z contains independent standard-normal draws. Small sigma favours smooth features, while larger sigma allows faster oscillations.

The draw is random and does not insert the exact target frequencies by construction. Very large bandwidth can also introduce unwanted oscillations between constraints, so larger is not automatically better.

中文讲稿

σ i 是频率分支 i 的标准差，Z 包含独立标准正态随机数。较小 σ 倾向平滑特征，较大 σ 允许更快的振荡。

这是随机抽样，并没有按构造塞入精确目标频率。过大的带宽还可能在约束之间产生不需要的振荡，因此并非越大越好。

9. Different scales share one nonlinear core

uθ(x)=a⊤[hθ(γB1(x)),hθ(γB2(x))]+cu_\theta(x)=a^\top[h_\theta(\gamma_{B_1}(x)),h_\theta(\gamma_{B_2}(x))]+cuθ​(x)=a⊤[hθ​(γB1​​(x)),hθ​(γB2​​(x))]+c

H theta denotes the same tanh core applied to each frequency branch, with shared weights and biases. Each branch has eight random frequencies and sixteen sine-cosine features in this experiment.

The two sixteen-unit core outputs are concatenated, then a and c form the learned scalar output. This follows the multiscale sharing pattern at a much smaller size than the original benchmarks.

中文讲稿

h θ 表示每个频率分支使用相同的双曲正切核心，共享权重与偏置。这个实验的每个分支有八个随机频率，组成十六个正弦余弦特征。

两组十六单元核心输出先拼接，再由 a 和 c 形成待学习的标量输出。这保留多尺度共享方式，但规模远小于原始基准。

10. Frequencies stay fixed; spatial derivatives pass through

∂xxsin⁡(2πbx)=−(2πb)2sin⁡(2πbx)\partial_{xx}\sin(2\pi bx)=-(2\pi b)^2\sin(2\pi bx)∂xx​sin(2πbx)=−(2πb)2sin(2πbx)

B is stored as a fixed buffer and never updated by the optimiser. This is different from learning frequency values or fitting them directly to reference temperatures.

Automatic differentiation must still pass through the feature map when differentiating with respect to x. Omitting the two pi b factors would change the physical residual and invalidate the comparison.

中文讲稿

B 保存为固定缓冲量，优化器从不更新它。这不同于学习频率数值，也不同于直接用参考温度拟合频率。

对 x 求导时，自动微分仍必须穿过特征映射。遗漏二圆周率 b 因子会改变物理残差，使对照失效。

14. From fixed frequencies to full spatial autodiff

a_i = 2 * pi * x @ B[i].reshape(1, -1)
h_i = tanh(core(cat((cos(a_i), sin(a_i)), 1)))
u = output(cat((h_1, h_2), dim=1))

Registering B as a buffer keeps random frequencies fixed while preserving them in the saved model. The sine-cosine map remains inside the forward computation graph.

The final line abbreviates two automatic derivatives with graph construction enabled in the downloadable implementation. Both branches share the core, and training updates their common weights plus the output layer.

The blue and purple curves track absolute coefficient errors for the one-cycle and six-cycle modes of multiscale seed eleven. Coefficients are obtained by independent trapezoidal projections of the predicted field, not by reading network weights.

These two projection errors are useful, but they do not measure every possible field distortion. Extra oscillations or other shapes can still create a large total error, and the two modes do not improve at guaranteed equal rates.

20. Why can low-band features also learn the ripples?

The nonlinear tanh core composes and mixes input features, so a small input bandwidth does not impose a strict band limit on the output. Random draws and nonlinear optimisation both affect what becomes learnable within a finite budget.

This observation does not contradict the paper’s motivation for changing preferred directions. It does show that choosing a larger or mixed bandwidth requires validation rather than an assumed improvement.

中文讲稿

非线性双曲正切核心会组合与混合输入特征，因此较小输入带宽并不构成输出的严格带限。随机抽样与非线性优化共同影响有限预算内能够学到什么。

这不否定论文改变偏好方向的动机。它说明更大或混合带宽需要验证，不能预先假定一定改善。

21. Keep the method and state the experiment’s limits

We preserve fixed random Fourier maps, a shared nonlinear core and concatenated branch outputs. The source, network size and budget are deliberately smaller teaching choices, and all twelve outcomes remain downloadable.

We have not reproduced the paper’s original high-frequency, wave or reaction-diffusion benchmarks. Nor does the output-kernel illustration verify constant-kernel assumptions or predict the complete derivative-constrained PINN dynamics.

中文讲稿

保留固定随机傅里叶映射、共享非线性核心与分支输出拼接。热源、网络大小和预算刻意采用更小的教学设置，全部十二次结果都可以下载。

没有复现论文原始的高频、波动或反应扩散基准。输出核示意也没有验证常核假设，更没有预测受导数约束的完整 PINN 动力学。

22. Predict before changing bandwidth and sampling

If b doubles while the sine amplitude stays fixed, its second-derivative amplitude becomes four times larger. Predict how this can affect optimisation and whether the existing residual points still resolve the resulting oscillations.

Run any changed bandwidth or sampling experiment into a new output file. Compare all seeds, independent field and mode errors, and residuals at shifted points before deciding whether the change helped.

中文讲稿

如果 b 加倍而正弦幅值不变，二阶导数幅值会变成四倍。先预测这如何影响优化，以及现有残差点还能否分辨产生的振荡。

改变带宽或采样的实验必须另存输出。比较全部种子、独立场与模态误差，以及偏移点残差，再判断改变是否有效。

23. Next: move from global features to local decomposition

Global Fourier features change preferred spatial patterns, but a single shared representation can remain sensitive to bandwidth and random initialisation. Our mixed-band failures make that limitation concrete.

The next paper is F B PINNs, which combines local subnetworks with spatial windows. We will ask whether dividing the representation spatially provides a different way to handle multiple scales within a small CPU budget.

中文讲稿

全局傅里叶特征改变偏爱的空间模式，但单个共享表示仍可能对带宽和随机初始化敏感。这里混合频带的失败具体展示了这个局限。

下一篇研究 FBPINNs，把局部子网络与空间窗口组合。我们将问，空间上分解表示，能否在小型 CPU 预算内提供另一种处理多尺度的方法。

Teaching checks and reference answers

Ask for a prediction before running the exercise. Analytic expectations do not guarantee an optimiser outcome.

If frequency doubles with fixed sine amplitude, what changes in the second derivative, and what must be revalidated?

The second derivative contains the square of angular frequency, so its amplitude grows by four. A Fourier mapping must remain in the spatial-autodiff graph even when its frequency buffer is fixed. Larger derivative scales can alter conditioning and the residual sampling needed to resolve oscillations. There is no guarantee that larger bandwidth improves the temperature field or all seeds. Compare independent complete-field errors, modal projections, endpoint errors and shifted residual checks; save modified runs separately. 保持正弦幅值不变，频率加倍后，二阶导数如何改变，又需要重新验证什么？

二阶导数包含角频率的平方，因此幅值增大四倍。即使频率缓冲量固定，傅里叶映射也必须保留在空间自动微分图内。导数尺度变大可能改变条件数与分辨振荡所需的残差采样。更大带宽不保证改善温度场或所有种子。必须同时比较独立完整场误差、模态投影、端点误差与偏移点残差，并把修改运行另存。只匹配两个模态系数，无法排除其他错误形状。
