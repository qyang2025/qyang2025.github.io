1. Paper19: DeepONet and function-to-field operator learning

First connect varying heat sources with a solution operator and a finite function family. Then explain branch,trunk,feature products and supervised training across functions. Finally compare held-out inputs,structural linearity,extrapolation,sensor ambiguity and physical residuals before adding physics.

中文讲稿

先把变化热源与解算子、有限函数族连接。再解释分支、主干、特征乘积以及跨函数监督训练。最后比较未训练输入、结构线性、外推、传感歧义与物理残差，再衔接物理信息方法。

2. Learn a map between functions, instead of only one field

The attention lesson still trained for one chosen boundary-value problem. If its source changes, do we have to optimise a new network again?

DeepONet learns a function-to-function map. We will use a tiny family of heat sources, then test new inputs without retraining.

中文讲稿

注意力这一讲，仍然为一个选定边值问题训练。如果热源变了，是否必须重新优化网络？

DeepONet 学习函数到函数的映射。我们采用一个极小热源族，再测试新输入，而不重新训练。

3. A changed source produces a different steady temperature field

The upper curve is a signed heat source f. Positive and negative values mean heating and cooling relative to a reference. The lower curve is the resulting temperature u.

We change the source and recompute its exact steady field. This is a parameter sweep, not transient heating. The two vertical axes use separate scales.

中文讲稿

上方曲线是带正负号的热源 f，正负表示相对参考的加热与冷却。下方是相应温度 u。

这里改变热源，并重新计算精确稳态场。这是参数扫描，不是瞬态加热；两条纵轴分别缩放。

4. Keep the physics fixed and vary the input function

−uxx=f,u(0)=u(1)=0-u_{xx}=f,\quad u(0)=u(1)=0−uxx​=f,u(0)=u(1)=0

X is position on the unit rod, and the subscript x x means a second spatial derivative. Conductivity is scaled to one, and both endpoints are held at zero.

The solution operator G maps the whole source function f to the whole temperature field u. G of f at x means evaluating that output field at one query location.

中文讲稿

x 是单位杆上的位置，下标 x x 表示空间二阶导数。导热率缩放为一，两端温度固定为零。

解算子 G 把整个热源函数 f 映射为整个温度场 u。G 作用于 f 后在 x 处取值，就是查询输出场的一个位置。

5. Begin with a small family of three sine modes

f(x)=∑m=13amsin⁡(mπx)f(x)=\sum_{m=1}^{3}a_m\sin(m\pi x)f(x)=m=1∑3​am​sin(mπx)

M indexes the three spatial sine modes, and a m is the amplitude of mode m. Training coefficients are drawn between minus one and one.

This defines our compact dataset, not Fourier-feature layers inside the network. The branch receives sampled source values, not the three coefficients as privileged input.

中文讲稿

m 编号三个空间正弦模式，a m 是第 m 个模式振幅。训练系数从负一到一之间抽取。

这定义了小型数据集，不是给网络加入傅里叶特征层。分支接收的是采样热源值，不会额外获得三个系数。

6. Second derivatives give a cheap exact validation reference

u∗(x)=∑m=13am(mπ)2sin⁡(mπx)u^*(x)=\sum_{m=1}^{3}\frac{a_m}{(m\pi)^2}\sin(m\pi x)u∗(x)=m=1∑3​(mπ)2am​​sin(mπx)

Differentiate a sine mode twice: it picks up minus m pi squared. The displayed denominator therefore makes negative u x x equal the source. The star marks the exact reference.

Higher-frequency source patterns produce smaller temperature amplitudes in this problem. Analytic fields provide cheap supervised labels and independent tests; we do not need a large simulation campaign.

中文讲稿

正弦模式求两阶导数，会乘上负的 m π 平方。因此显示的分母，使负 u x x 等于热源。星号表示精确参考。

在这个问题中，更高频热源产生更小的温度振幅。解析场可以提供便宜的监督标签与独立测试，不需要大规模模拟。

7. Encode each input function with nine fixed sensors

f=[f(x1),…,f(x9)]\boldsymbol f=[f(x_1),\ldots,f(x_9)]f=[f(x1​),…,f(x9​)]

Bold f is the vector of nine source readings. The sensor locations are fixed midpoint positions along the rod, and remain the same for every input function.

Do not confuse a new function with a new query position. Changing the source changes this whole input vector; changing the query asks for another point of its output field.

中文讲稿

粗体 f 是九个热源读数构成的向量。传感器固定在杆上的中点位置，对每个输入函数都相同。

不要把新函数与新查询位置混为一谈。改变热源会改变整组输入向量；改变查询，只是在同一输出场上换个位置。

8. The branch encodes which input function we have

b=Bθ(f)\boldsymbol b=B_\theta(\boldsymbol f)b=Bθ​(f)

B theta is the branch network, and theta collects trainable weights and biases. It maps the sensor vector to eight learned coefficients, b.

Those coefficients are latent features. They are not forced to equal the three physical sine amplitudes, and should not be assigned that interpretation without checking.

中文讲稿

B θ 是分支网络，θ 收集待训练权重和偏置。它把传感向量映射为八个学习系数 b。

这些系数是潜在特征，不被强制等于三个物理正弦振幅。没有检查之前，不应直接赋予那种解释。

9. The trunk encodes where we want to query

t=Tθ(x)\boldsymbol t=T_\theta(x)t=Tθ​(x)

T theta is the trunk network. It turns the query location into eight spatial features, t. These features do not depend on which source was supplied.

The source-dependent branch coefficients will combine with those spatial features. This separates conditioning on a function from evaluating an output location.

中文讲稿

T θ 是主干网络，把查询位置变成八个空间特征 t。它们不依赖本次提供的是哪一个热源。

依赖热源的分支系数将与这些空间特征组合。这把函数条件信息与输出位置查询分开。

10. Multiply corresponding features, then sum them

hθ(f,x)=∑k=18bktk(x)+b0h_\theta(f,x)=\sum_{k=1}^{8}b_k t_k(x)+b_0hθ​(f,x)=k=1∑8​bk​tk​(x)+b0​

K indexes matching latent features, and b zero is a learned shared scalar bias. H theta names this raw branch–trunk combination.

The dot product lets one encoded source modulate an entire spatial field. In the next step, we wrap this raw output with the same boundary factor used by every control.

中文讲稿

k 编号对应的潜在特征，b 零是学习的共享标量偏置。h θ 表示分支与主干的原始组合。

点积让一个编码热源调节整个空间场。下一步，对这个原始输出施加所有对照共用的边界因子。

11. The common hard boundary is an added teaching construction

uθ(f,x)=x(1−x)hθ(f,x)u_\theta(f,x)=x(1-x)h_\theta(f,x)uθ​(f,x)=x(1−x)hθ​(f,x)

Multiplication by x times one minus x makes both endpoint predictions exactly zero. This extra wrapper is shared by our DeepONet, linear-branch and concatenation controls.

It is an engineering adaptation, not a claim that the original architecture inherently satisfies every boundary condition. It also does not enforce the interior Poisson equation.

中文讲稿

乘以 x 乘一减 x，使两端预测严格为零。DeepONet、线性分支与拼接对照，都共用这个额外包装。

这是工程适配，不表示原架构天然满足任意边界条件。它也没有强制内部 Poisson 方程成立。

12. Split by input function, instead of only splitting query points

We train on twenty-four source functions, with twelve temperature labels for each. That gives two hundred and eighty-eight paired output observations.

The main test uses sixteen different source functions on a dense spatial grid. Splitting only query points of the same functions would answer an easier question than generalisation to a new source.

中文讲稿

训练使用二十四个热源函数，每个提供十二个温度标签，总计二百八十八对输出观测。

主要测试使用十六个不同热源，并在密集空间网格上评估。只拆分同一函数的查询点，回答的是比新热源泛化更容易的问题。

13. Encode the branch once and combine many query locations

B = branch(source_sensor_values)  # functions ×8
T = trunk(query_positions)       # positions ×8
raw = B @ T.T + shared_bias
u = raw * (x*(1-x))[None,:]
loss = mean(((u - labels)/scale)**2)

The rows of B correspond to input functions, and the rows of T correspond to query locations. Their matrix product evaluates every function–position pair.

This factorisation avoids repeating branch evaluation for each location. It is still supervised training here: the loss contains temperature labels, and no differential-equation residual.

中文讲稿

B 的行对应输入函数，T 的行对应查询位置。矩阵乘积同时评估每个函数与位置的组合。

这样可以避免为每个位置重复计算分支。但这里仍然是监督训练：损失包含温度标签，没有微分方程残差。

14. Compare structures without pretending their capacities are identical

We compare an unstacked nonlinear-branch DeepONet with a concatenation network and a linear-branch variant. All see the same labels and use two thousand four hundred updates.

Parameter counts differ, and a shared seed number does not mean identical initial functions across architectures. These are informative controls, not a perfectly isolated architecture ranking.

中文讲稿

比较非线性分支的非堆叠 DeepONet、拼接网络和线性分支变体。它们看到相同标签，都使用两千四百步。

参数数目不同，相同种子编号也不意味着不同架构的初始函数相同。这些对照提供信息，不构成完全隔离的架构排名。

17. What does a linear branch guarantee for a linear problem?

B(f)=Wf,b0=0B(\boldsymbol f)=W\boldsymbol f,\quad b_0=0B(f)=Wf,b0​=0

W is a learned matrix with no branch bias, and we remove the shared output bias. The trunk can remain nonlinear in x. The resulting field is exactly linear in the sensor vector.

This construction guarantees a zero output for a zero input and preserves midpoint superposition. It does not guarantee an accurate Poisson inverse, and is a problem-specific control rather than a universal DeepONet prescription.

中文讲稿

W 是没有分支偏置的学习矩阵，同时移除共享输出偏置。主干仍可对 x 非线性，但最终场对传感向量严格线性。

这个构造保证零输入得到零输出，并保持中点叠加。它不保证 Poisson 逆算子准确，是问题特定对照，不是通用 DeepONet 配方。

18. Structural identities and predictive accuracy are separate questions

G ⁣(f+g2)=G(f)+G(g)2G\!\left(\frac{f+g}{2}\right)=\frac{G(f)+G(g)}2G(2f+g​)=2G(f)+G(g)​

Here g is a second source function. The plot measures deviation from this midpoint identity. The linear branch satisfies it up to floating-point roundoff.

The other models are not constructed to obey it exactly. Even exact linearity does not reveal the correct response in a new input direction that training never constrained.

中文讲稿

这里 g 是另一个热源函数。图中测量偏离中点恒等式的程度；线性分支满足它，误差接近浮点舍入。

其他模型没有被构造成严格满足它。但即使线性完全准确，也不能自动知道未受训练约束的新输入方向应有什么响应。

21. Finite sensors can also make two functions indistinguishable

f(x)=sin⁡(18πx),f(xj)=0,xj=(j+12)/9f(x)=\sin(18\pi x),\quad f(x_j)=0,\quad x_j=(j+\tfrac12)/9f(x)=sin(18πx),f(xj​)=0,xj​=(j+21​)/9

J runs from zero through eight in this indexing convention. Every sensor lands on a zero of this oscillating source. The zero source gives the same nine readings.

Yet the two sources have different exact temperature fields. No deterministic network receiving only those readings can distinguish them. This is an analytic information limit outside our restricted training family.

中文讲稿

这里 j 从零编号到八。每个传感器都落在振荡热源的零点上，零热源也给出同样的九个读数。

但两个热源的精确温度场不同。只接收这些读数的确定性网络无法区分它们。这是受限训练族之外的解析信息极限。

22. Universal approximation is not a training or extrapolation certificate

The paper’s operator theorem motivates the branch–trunk structure. It concerns approximation capacity under its assumptions, not a guarantee for this tiny trained network.

Finite sensors, limited function coverage and imperfect optimisation remain practical limitations. A universal-approximation statement does not promise arbitrary functions will be identified from nine readings.

中文讲稿

论文的算子定理为分支—主干结构提供动机。它讨论假设下的逼近能力，不是对这个小训练网络的保证。

有限传感器、受限函数覆盖和不完美优化，仍然构成实际限制。通用逼近陈述不保证九个读数能够识别任意函数。

23. After fitting temperature labels, check the physical residual too

r(f,x)=−∂xxuθ(f,x)−f(x)r(f,x)=-\partial_{xx}u_\theta(f,x)-f(x)r(f,x)=−∂xx​uθ​(f,x)−f(x)

R is the Poisson residual of the predicted operator output. We compute it at one hundred and ninety-seven shifted locations for held-out source functions.

These residuals were not in the supervised training objective. Small label error does not force correct derivatives, which gives a direct reason to add physics in the next paper.

中文讲稿

r 是预测算子输出的 Poisson 残差。对未训练热源，在一百九十七个偏移位置计算它。

这些残差没有进入监督训练目标。小标签误差不会强迫导数正确，这正是下一篇加入物理的直接动机。

24. This is a finite three-mode family, not an arbitrary-operator benchmark

Our dataset uses a known analytic linear operator and a small three-mode source family. The experiment teaches conditioning, latent products and generalisation checks with cheap labels.

It does not reproduce the paper’s Gaussian-random-field studies or broad nonlinear-operator benchmarks. Hard boundary factors and the linear-branch control are disclosed adaptations, and every failed final outcome is retained.

中文讲稿

数据集使用已知解析线性算子和小型三模态热源族。实验用便宜标签讲解条件信息、潜在特征乘积和泛化检查。

没有复现原文高斯随机场研究或广泛非线性算子基准。硬边界因子与线性分支对照是明确说明的适配，并保留全部失败最终结果。

25. Do nine zero readings prove that the source is zero?

sin⁡(18πxj)=0  ⇏  sin⁡(18πx)=0  ∀x\sin(18\pi x_j)=0\;\not\Rightarrow\;\sin(18\pi x)=0\;\forall xsin(18πxj​)=0⇒sin(18πx)=0∀x

Within our three-mode family, the nine-sensor matrix has full column rank. There, nine zero readings do identify zero coefficients.

Outside that family, the eighteenth-mode example defeats the conclusion. Always state the admissible function class before claiming that sensor values identify a physical input.

中文讲稿

在三模态族内，九传感器矩阵具有满列秩。因此在这个族里，九个零读数确实确定零系数。

但超出这个函数族，第十八模式反例就推翻结论。在声称传感值识别物理输入之前，必须说明允许的函数类别。

26. Next: put the equation into operator training

We have learned a source-to-temperature map from paired examples. But obtaining many output fields may be expensive, and a good data fit need not obey the equation.

Physics-informed DeepONets add a residual loss for each training input function. We will compare sparse labels, pure physics and their combination while keeping the architecture fixed.

中文讲稿

我们已从成对样例学习热源到温度映射。但获取大量输出场可能昂贵，良好数据拟合也未必遵守方程。

Can exact input linearity recover a never-seen frequency response?

No. Linearity constrains sums and scaling of responses, but training on the first three source modes does not determine the response to an independent fourth mode. Nine sensors distinguish that fourth mode; the observed failure is missing training coverage. A separate sin(18 pi x) construction vanishes at all nine midpoint sensors and proves a genuine information ambiguity outside the restricted three-mode family. Inspect unseen-input fields and shifted PDE residuals rather than treating a structural identity as an accuracy certificate.

G(af+bg)=aG(f)+bG(g)G(af+bg)=aG(f)+bG(g)G(af+bg)=aG(f)+bG(g)

输入上的严格线性能恢复未见频率的响应吗？

不能。线性限制响应的叠加与缩放，但前三个模式的训练并不确定第四个独立模式的响应。九个传感器能够分辨第四模式，因此该失败属于缺少训练覆盖。另一个 sin(18πx) 构造在全部中点传感器上为零，证明受限训练族之外还存在真正的信息歧义。需要检查新输入的场与偏移位置物理残差，不能把结构恒等式当成精度证书。
