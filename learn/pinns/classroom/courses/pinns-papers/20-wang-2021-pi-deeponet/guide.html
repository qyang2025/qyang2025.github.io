First connect source functions, physical information and a shared branch–trunk architecture. Then derive the per-input residual and explain the matched training controls. Finally inspect saved training, independent fields, residuals and extrapolation before concluding the twenty-paper route.

−uxx=f,u(0)=u(1)=0-u_{xx}=f,\qquad u(0)=u(1)=0−uxx​=f,u(0)=u(1)=0

The subscript x x means the second spatial derivative. Conductivity has been scaled to one, and both endpoint temperatures are zero.

For each source function f, the operator must produce a different field satisfying this same rule. We are learning many related solutions with one shared set of weights.

对每个热源函数 f，算子都应输出满足同一规律的不同温度场。一个共享参数集合学习许多相关解。

5. No output labels does not mean no known information

Physics-only training still knows the source at every residual location. It also knows the differential equation and the boundary conditions.

What it does not receive is the exact temperature at training queries. We keep exact solutions separately for evaluation and for the explicitly labelled controls.

中文讲稿

纯物理训练仍知道每个残差位置的热源，也知道微分方程与边界条件。

它不接收训练查询位置的精确温度。精确解单独用于评估，以及明确标注的数据对照。

8. Guarantee the endpoints by construction, then learn the interior physics

uθ(f,x)=p(x)vθ(f,x),p(x)=x(1−x)u_\theta(f,x)=p(x)v_\theta(f,x),\quad p(x)=x(1-x)uθ​(f,x)=p(x)vθ​(f,x),p(x)=x(1−x)

P is a fixed boundary factor. Multiplying by x times one minus x makes both endpoints exactly zero for every input function.

This removes a boundary penalty from our comparison. It does not make the interior correct, and it is our teaching construction rather than a requirement of the paper.

中文讲稿

p 是固定边界因子。乘上 x 与一减 x，让每个输入函数对应的两个端点严格为零。

这使比较无需边界惩罚，但不会保证内部正确。它是教学构造，不是论文对架构的要求。

9. Each source has its own equation mismatch

R is the residual: minus the predicted temperature curvature, minus the known source. A zero value means the differential equation holds at this one function and position.

The spatial derivative keeps the source vector fixed. We differentiate the query coordinate, not the list of sensor readings.

r 是残差：预测温度曲率取负，再减已知热源。零值意味着这个函数、这个位置满足微分方程。

空间求导时保持热源向量固定。求导对象是查询坐标，不是传感器读数列表。

I counts training functions and J counts residual positions for each function. Here twenty-four times sixteen gives three hundred and eighty-four physics constraints.

These are sampled constraints, not an exact integral or a proof over every source. The same shared weights must reduce all of them together.

11. Differentiate the boundary factor too: retain the cross term

This is the product rule applied twice. V x and v x x are the first and second query derivatives of the unwrapped prediction v.

The middle term comes from differentiating both factors once. Dropping it would train the wrong physical equation even if the loss became small.

中文讲稿

这是两次乘积求导。v x 与 v x x 是未包装预测 v 对查询位置的一阶、二阶导数。

中间项来自两个因子各求一次导数。漏掉它，即使损失很小，也是在训练错误的物理方程。

12. Use checked analytic trunk derivatives to keep the CPU experiment small

The paper uses automatic differentiation. Our tiny tanh trunk has simple analytic first and second derivatives, which avoid repeating expensive coordinate graphs.

We independently compare outputs, both derivatives and parameter gradients against full automatic differentiation. The formulas remain differentiable with respect to the weights; they are not detached training targets.

中文讲稿

原文使用自动微分。这个小型 tanh 主干的一阶、二阶导数有简单解析表达，可减少重复坐标计算图。

独立测试把输出、两阶导数以及参数梯度与完整自动微分比较。解析公式仍可对权重求导，并非脱离训练图的目标。

13. One training step: known source, predicted field, checked curvature

B = branch(source_sensor_values)
u, ux, uxx = field_with_derivatives(B, x)
r = -uxx - known_source_at_x
loss = mean(r**2)
loss.backward(); optimiser.step()

First evaluate the branch for each source and the trunk derivatives at query positions. Combine them with the boundary factor to obtain the full second derivative.

Subtract the known forcing, square and average. Backpropagation then updates both branch and trunk. No exact training temperature is requested in this physics-only path.

先对各热源计算分支，在查询位置计算主干导数，再结合边界因子得到完整二阶导数。

减去已知热源，平方并平均。反向传播同时更新分支与主干。纯物理路径不请求任何精确训练温度。

20. Physics training does not automatically remove input-coverage limits

Circles use larger amplitudes; squares use the unseen fourth source mode. The fourth mode did not occur in any training residual, even in physics-only training.

All three models can fail outside the trained family. Knowing a physical equation is useful, but this finite learned operator has not solved it exactly for every possible input.

中文讲稿

圆点使用更大振幅，方块使用未见第四热源模式。即使纯物理训练，第四模式也从未出现在训练残差中。

三个模型都可能在训练族外失败。知道物理方程有帮助，但有限学习算子并未精确求解每一种可能输入。

21. Finite-sensor information limits still apply

Recall the last lesson’s source that vanished at all nine sensors. A deterministic branch cannot distinguish that source from zero using those readings alone.

Adding residuals on the limited training family does not change that representation limit for arbitrary new inputs. More useful sensors or a restricted input class may be necessary.

中文讲稿

回忆上一讲在九个传感器上都为零的热源。确定性分支仅靠这些读数无法把它与零热源区分。

在有限训练族上增加残差，不会改变任意新输入的表示极限。可能需要更有信息的传感器，或明确限制输入类别。

23. What does training without temperature labels still know?

Pause here. If a physics-only model never sees exact temperatures during training, is it learning without information?

It still sees known source functions, the equation and endpoint conditions. To judge the learned map, test new inputs and independent positions against a separate reference. A small sampled residual alone is not a certificate.

中文讲稿

在这里停一下。如果纯物理模型训练时从未看到精确温度，是不是没有信息也能学习？

它仍看到已知热源函数、方程与端点条件。评估学习映射，要把新输入和独立位置与单独参考比较。小的采样残差本身不是证书。

24. Twenty-paper route: from solving one problem to learning a family

We began with a neural field for one equation, then examined inverse problems, training difficulties and independent physical checks. The extensions added decomposition, attention and function-to-function learning.

The common habit is unchanged: explain the physical picture, state the available information, compare fair controls and check unseen cases. Those habits matter more than a new architecture name.

中文讲稿

从一个方程的神经场出发，路线经过反问题、训练困难与独立物理检查。扩展部分加入分区、注意力以及函数到函数学习。

共同习惯没有改变：解释物理图像，明确已有信息，比较合理对照，检查未见情况。这些习惯比新增架构名称更重要。

Teaching checks and reference answers

Ask for a prediction before running the exercise. Analytic expectations do not guarantee an optimiser outcome.

Does physics-only operator training learn without information?

No. It uses known source functions, a specified differential equation and boundary conditions, with residual constraints for each training function. It avoids paired training-temperature labels. This differs from having no information, and also differs from validation without reference solutions. Independent unseen input functions, shifted residual positions and full-field comparisons remain necessary. Finite residual sampling and sensor encoding do not certify arbitrary-input generalisation.
